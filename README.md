# 📌 Overview

**CleanInsights** is a no-code exploratory data analysis and data cleaning application built with **Streamlit**.

Upload a CSV or Excel dataset and instantly explore, visualize, clean, and export your data through an interactive web interface.

No notebooks. No scripting. Just upload and analyze.

---

# ✨ Features

| | |
|---|---|
| 📊 **Dataset Health Score** | Automatic quality score based on missing values, duplicates, constant columns, and outlier density. |
| 🗂️ **Feature Summary** | Automatically classifies Numeric, Categorical, Boolean, Datetime, and Object columns. |
| 🔍 **Missing Value Analysis** | Interactive Plotly bar chart showing missing values sorted by severity. |
| 📈 **Distribution Analysis** | Histogram and Box Plot for any numeric feature. |
| 🔗 **Correlation Heatmap** | Interactive Pearson, Spearman, and Kendall correlation matrix. |
| 📋 **Categorical Analysis** | Value counts, Top-N selector, and interactive charts. |
| 🧹 **Data Cleaning Pipeline** | Missing value handling, duplicate removal, outlier detection, and column management. |
| 💾 **Export Options** | Export cleaned datasets as CSV or Excel, plus a JSON cleaning report. |

# 🚀 Quick Start

```bash
git clone https://github.com/AryaBuwa/CleanInsights.git

cd CleanInsights

pip install -r requirements.txt

streamlit run main.py
```

Open:

```
http://localhost:8501
```

# 🧹 Cleaning Operations

| Category | Options |
|----------|---------|
| Missing Values | Keep, Drop Rows, Mean, Median, Mode, Constant Value, Random Sampling |
| Duplicates | Remove All, Keep First, Keep Last, Custom Subset |
| Outliers | IQR Remove, IQR Flag, Z-Score Remove, Z-Score Flag |
| Columns | Drop Selected Columns |
